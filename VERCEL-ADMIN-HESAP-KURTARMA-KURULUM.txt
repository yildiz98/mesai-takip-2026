MESAI TAKIP - BLAZE GEREKTIRMEYEN VERCEL ADMIN HESAP KURTARMA

AMAC
Admin panelindeki "🔑 Şifre Ata" butonunun Firebase Cloud Functions yerine Vercel Function kullanması.
Firebase SmartApart projesi Blaze'e yükseltilmez.

DOSYALAR
- api/admin-set-temporary-password.js : güvenli sunucu endpoint'i
- package.json : Firebase Admin SDK bağımlılığı ve Node 22
- vercel.json : Vercel Function ayarı
- firebase-mesai.js : admin butonu Vercel endpoint'ine bağlandı
- index.html : Firebase Functions script'i kaldırıldı

VERCEL ENVIRONMENT VARIABLE
Vercel Project Settings > Environment Variables bölümüne sadece Vercel'de şu değişken eklenir:

FIREBASE_SERVICE_ACCOUNT_JSON = Firebase service account JSON dosyasının TAM İÇERİĞİ

Bu JSON dosyası GitHub'a yüklenmez. Sohbete de gönderilmez.

Firebase service account JSON oluşturma:
Firebase Console > SmartApart > Project settings > Service accounts > Generate new private key

ÖNEMLİ
Service account JSON gizli anahtardır. GitHub'a, public ZIP'e veya frontend JavaScript dosyasına koyma.

DEPLOY
Vercel'de GitHub repository olarak mesai-takip-2026 seçilir.
Root Directory: ./
Framework Preset: Other
Node.js: 22.x
Deploy.

DEPLOY SONRASI
Vercel sana örneğin https://mesai-takip-2026.vercel.app gibi bir adres verir.
Bu adres firebase-mesai.js içindeki MESAI_BACKEND_URL değerine yazılmalıdır.
